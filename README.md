# Магазин электроники — учебный проект

Учебный проект на C# и .NET 10, демонстрирующий развитие консольного приложения от базовых конструкций языка до объектно-ориентированной организации кода.

Репозиторий содержит две самостоятельные версии магазина электроники. Исходный код версий разделён, поэтому каждую программу можно изучать и запускать отдельно.

## Версии проекта

### V1.0 — базовая консольная версия

Первая версия проекта, написанная без ООП. Для хранения каталога используется `Dictionary<string, double>`. Программа поддерживает просмотр ассортимента, поиск, добавление и удаление товаров, изменение цен, фильтрацию, сортировку и общую статистику.

Подробнее: README V1.0.

### V2.0 — объектно-ориентированная версия

Вторая версия развивает первоначальный проект. Логика магазина разделена на классы: товары, магазин, покупатель, корзина и заказы. Реализованы управление каталогом, оформление покупки, проверка остатков и сохранение истории заказов в рамках одного запуска программы.

Подробнее: README V2.0.

## Требования

- .NET 10 SDK.
- Visual Studio с поддержкой .NET 10 или другая подходящая среда разработки.

## Запуск

Чтобы открыть обе версии в Visual Studio, используйте общее решение `ElectronicsStoreManagementSystem.slnx`.

Каждую версию также можно запустить отдельно из корневой папки репозитория.

### V1.0

```powershell
dotnet run --project "versions/v1-basic-console/ElectronicsStoreManagementSystemV1.0/ElectronicsStoreManagementSystemV1.0.csproj"
```

### V2.0

```powershell
dotnet run --project "versions/v2-oop-console/ElectronicsStoreManagementSystem.V2.0/ElectronicsStoreManagementSystem.V2.0.csproj"
```

## Ограничения проекта

Обе версии являются учебными консольными приложениями, а не готовой системой для реального магазина.

V1.0 хранит каталог в памяти. V2.0 также хранит каталог, корзину, баланс и историю заказов только во время работы программы. После завершения приложения данные сбрасываются.

В V2.0 выбор режима администратора не защищён авторизацией. База данных и реальные платежи не реализованы.

## Цель проекта

Показать последовательное изучение C# на одном предметном примере: от простого хранения и обработки данных к классам, взаимодействию объектов и реализации базовой бизнес-логики.
