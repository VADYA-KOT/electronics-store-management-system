# Магазин электроники — учебный проект

Учебное консольное приложение на C# и .NET 10. Проект показывает основы ООП: классы и объекты, свойства, методы, инкапсуляцию, списки и взаимодействие объектов. Это демонстрация учебного пути, а не готовая система для реального магазина.

## Требования

- .NET 10 SDK

## Возможности

- Режим администратора: просмотр и поиск товаров, добавление, изменение цены и остатков, удаление товаров, просмотр заказов.
- Режим покупателя: каталог, корзина, изменение и удаление позиций, оформление заказа и просмотр истории.
- Проверка остатков в корзине и повторная проверка перед оформлением заказа.
- Заказ сохраняет названия и цены на момент покупки. Если товара или денег не хватает, заказ не оформляется и остатки не списываются.
- Если товар удалили из каталога, пока он находился в корзине, оформить его нельзя.

## Запуск

Из корневой папки репозитория выполните:

```powershell
dotnet run --project ElectronicsStoreManagementSystem.V2.0/ElectronicsStoreManagementSystem.V2.0.csproj
```

При запуске создаётся демонстрационный каталог: ноутбук, наушники, клавиатура и мышка. Выберите режим администратора или покупателя в главном меню. Режимы можно переключать во время одного запуска.

Каталог, корзина и история заказов хранятся только в памяти и сбрасываются после закрытия программы. Выбор режима администратора не защищён паролем и служит только для демонстрации разных меню.

## Основные классы

- `Product` хранит данные товара и проверяет цену и остаток.
- `Store` управляет каталогом и оформляет заказы.
- `Customer` хранит баланс, корзину и историю заказов.
- `Cart` и `CartItem` представляют корзину и её позиции.
- `Order` и `OrderItem` хранят заказ и цены на момент покупки.

## Пример покупки

1. Выберите режим покупателя.
2. Откройте каталог и добавьте товар по ID и количеству.
3. Проверьте корзину и подтвердите оформление.
4. История заказа доступна покупателю, а администратор увидит заказ в своём меню.
