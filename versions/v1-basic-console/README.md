# V1.0 — базовая консольная версия

Первая учебная версия магазина электроники на C# и .NET 10.

В этой версии основное внимание уделено базовым конструкциям языка: переменным, условным операторам, циклам, словарям, обработке пользовательского ввода и LINQ. Классы предметной области и объектно-ориентированная логика магазина не используются.

## Возможности

- Просмотр ассортимента.
- Поиск товара по точному названию.
- Добавление и удаление товаров.
- Изменение цены существующего товара.
- Фильтрация товаров по цене и диапазону цен.
- Сортировка по возрастанию или убыванию цены.
- Сортировка названий по алфавиту в обоих направлениях.
- Общая статистика: количество товаров, средняя цена, самый дешёвый и самый дорогой товар.

Пункты управления покупателями, создания заказов и расширенного анализа пока не реализованы.

## Используемые средства

- C#.
- .NET 10.
- `Dictionary<string, double>` для хранения названий и цен товаров.
- Циклы и `switch` для организации меню.
- LINQ для фильтрации, сортировки и вычисления статистики.

## Запуск

Из корневой папки репозитория выполните:

```powershell
dotnet run --project "versions/v1-basic-console/ElectronicsStoreManagementSystemV1.0/ElectronicsStoreManagementSystemV1.0.csproj"
```

Также проект можно открыть в Visual Studio через общее решение репозитория или соответствующий файл проекта.

## Ограничения

- Поиск выполняется по точному названию товара с учётом регистра.
- Каталог хранится только в памяти и сбрасывается после завершения программы.
- Управление покупателями и создание заказов не реализованы.
- Расширенные разделы анализа пока представлены сообщениями о разработке.

V1.0 сохраняет первоначальный простой подход к решению задачи и служит основой для сравнения с последующей объектно-ориентированной версией.
